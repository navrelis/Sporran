# Sporran Compatibility Modules
This folder contains several different compatibility layers designed specifically to
bridge two mods with each other, and have configs to allow the user to pick and choose what they want.

They will likely be their own mods, to not bloat the base Sporran module more than it already is. **However, both mods are still required to be installed on
the user's instance.**

## Supported Bridges
| Mods                                                                                                                                | Bridge                         |
|-------------------------------------------------------------------------------------------------------------------------------------|--------------------------------|
| Forge Energy, Reborn Energy                                                                                                         | Sporran: Transfer API Compat      |
| [Trinkets](https://modrinth.com/mod/trinkets), [Curios](https://modrinth.com/mod/curios)                                            | Sporran: Curios & Trinkets Compat |
| [Sodium](https://modrinth.com/mod/sodium), [Immersive Engineering](https://modrinth.com/mod/immersiveengineering), other Forge mods | Sporran: Forge Mods Compat        |
| [Create Fabric](https://modrinth.com/mod/create-fabric), any Create Forge addons                                                    | Sporran: Create Compat            |
| [ModernFix](https://modrinth.com/mod/modernfix), [GeckoLib](https://modrinth.com/mod/geckolib), any other Fabric mods               | Sporran: Fabric Mod Compat        |
